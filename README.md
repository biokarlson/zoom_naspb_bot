# Zoom bot

Реализовано по ТЗ: заявки (FSM), проверка занятости (бот + Яндекс Календарь), одобрение/отклонение,
создание встреч в Zoom (PMI, type 2/3) и событий в календаре, отмена (по запросу и админом),
списки «Мои встречи» / «Все встречи», шаблон инструкции и дополнительный текст (отдельным сообщением после инструкции), подключение Zoom и CalDAV из бота.

## Запуск
1. Python 3.10+, `pip install -r requirements.txt`
2. Переменные окружения — см. `.env.example` (ключ: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`)
3. В `config.py` вписать `ADMIN_IDS`
4. `python main.py`
5. В боте: /start → Управление → «Подключить Zoom» и «Подключить календарь»

## Структура
- `bot/handlers/` — start, request (FSM), review (одобрить/отклонить/проверить), meetings (списки, карточки, отмена), admin_settings
- `services/` — zoom, caldav_client, availability, recurrence, approval, cancellation, templating, series
- `db/` — модели и репозиторий (SQLite)
- `web/oauth.py` — /zoom/callback

## Важно
- Не проверено на реальных Zoom и Яндекс CalDAV: первый прогон делайте на тестовых данных.
- Заявки/отмены обрабатываются защищённо от двойных нажатий (атомарная смена статуса + блокировка в процессе).
- «Все встречи» показывает статусы: на рассмотрении, одобрена, отмена запрошена.
- Состояние OAuth и FSM хранится в памяти: после перезапуска бота диалоги сбрасываются.

## Ссылки на встречи
- Общая ссылка (PMI) — по умолчанию для всех встреч и серий.
- При пересечении по времени создаётся отдельная комната (не PMI). Ссылка выбирается автоматически при одобрении.
- Серия получает одну ссылку на все занятия: общую, если ни одно занятие не пересекается с встречей на общей ссылке, иначе отдельную.
- В один слот помещаются максимум две встречи (общая + одна отдельная); третью одобрить нельзя.
- События календаря, созданные не ботом, считаются занятыми общей ссылкой.
- В БД появились колонки link_kind и overlap_flag; в существующую SQLite-базу они добавляются автоматически при запуске.

## Навигация
- Постоянная кнопка «🏠 Главное меню» внизу экрана (появляется после /start; существующим пользователям нужно один раз нажать /start).
- Меню команд: /start, /request, /my, /cancel.

## Дополнительный текст
После одобрения автор получает два сообщения: инструкцию по шаблону и (если задан) дополнительный текст отдельным сообщением.
Переменной {extra_text} в шаблоне больше нет; шаблон с ней не проходит проверку, и до пересохранения используется стандартный.

## Ссылки в инструкции
В «Управление» → «Ссылки в инструкции» админ задаёт свою ссылку для {join_url} и короткую ссылку для {join_short_url}.
Если задана хотя бы одна из них, подставляются только заданные (незаданная остаётся пустой). Ссылка из Zoom API берётся, если не задана ни одна или для встречи создана отдельная комната.
Календарь и карточки/списки в боте по-прежнему показывают ссылку из Zoom.
